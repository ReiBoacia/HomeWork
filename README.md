
## 学生成绩管理系统流程图

```text
学生成绩管理系统
│
├── 开始
│   │
│   ▼
├── 读取 file.txt
│   └── 文件不存在 → 初始化数据
│
├── 显示主菜单
│   │
│   ▼
├── 输入功能选项（1～6）
│   │
│   ├── 1. 录入学生信息
│   │   ├── 输入学号、姓名
│   │   ├── 输入语文、数学、英语成绩
│   │   ├── 自动计算总分
│   │   └── 保存数据 → 返回主菜单
│   │
│   ├── 2. 修改学生信息
│   │   ├── 按学号查找学生
│   │   ├── 修改学号、姓名或成绩
│   │   ├── 自动更新总分
│   │   └── 保存数据 → 返回主菜单
│   │
│   ├── 3. 删除学生信息
│   │   ├── 按学号查找学生
│   │   ├── 删除对应记录
│   │   └── 保存数据 → 返回主菜单
│   │
│   ├── 4. 查询学生信息
│   │   ├── 输入学生学号
│   │   ├── 显示学生信息及成绩
│   │   └── 返回主菜单
│   │
│   ├── 5. 成绩排序
│   │   ├── 选择排序科目
│   │   │   ├── 语文
│   │   │   ├── 数学
│   │   │   ├── 英语
│   │   │   └── 总分
│   │   ├── 按成绩从高到低排序
│   │   ├── 显示排名
│   │   └── 返回主菜单
│   │
│   ├── 6. 退出系统
│   │   └── 结束程序
│   │
│   └── 其他输入
│       └── 提示错误 → 返回主菜单
│
└── 结束
```
